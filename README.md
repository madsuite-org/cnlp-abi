# cnlp-abi (moved)

The cnlp ABI now lives in [madsuite-org/cnlplib](https://github.com/madsuite-org/cnlplib),
together with the registry of cnlp libraries and the `cnlp` command, with this repository's
history merged in. Documentation: https://cnlplib.madsuite.org.

This repository is archived and kept read-only so existing links keep working.
